**TaskFlow** — это полноценный Trello-клон для управления задачами. Проект создан для портфолио и демонстрирует современный стек технологий.

🔗 **Демо:** *[будет доступно после деплоя]*

---

## ✨ Функционал

- 📋 **Три колонки**: To Do, In Progress, Done
- 🎴 **Карточки задач**: название, описание, приоритет
- 🔄 **Drag & Drop**: перетаскивание задач между колонками
- ➕ **Создание задач**: в любую колонку
- ✏️ **Редактирование**: изменение названия, описания
- 🗑️ **Удаление**: с подтверждением
- 📊 **Статистика**: круговые диаграммы по статусу и приоритету
- 🌙 **Тёмная тема**: переключается одной кнопкой
- 💾 **LocalStorage**: все данные сохраняются локально
